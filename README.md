# FaitesVousConfiance — L. Sylla

Site web vitrine de **FaitesVousConfiance**, maison de mode, style et art de vivre (Vaud, Suisse).

Mode & vêtements · Accessoires capillaires · Conseil en style · Décoration d'intérieur.

## Technique

Site statique en HTML/CSS/JS (aucune dépendance, aucun build). Hébergé sur **GitHub Pages**.

```
index.html          Accueil
mode.html           Mode & Vêtements (+ boutique à venir)
accessoires.html    Accessoires capillaires
conseil.html        Conseil en style & image
deco.html           Décoration d'intérieur
apropos.html        À propos
contact.html        Contact
assets/css          Feuille de style commune
assets/js           Interactions (menu, animations, formulaire)
assets/logo         Logos et emblème
```

## Mise à jour du site

Modifier les fichiers, puis :

```bash
git add .
git commit -m "Mise à jour du site"
git push
```

GitHub Pages republie automatiquement en une à deux minutes.
